# Portfolio: Sumant Shivaram Gosi

Bilingual (English/German) portfolio for an automotive embedded software engineer. Built with Next.js (App Router), TypeScript and Tailwind CSS, deployed on Vercel.

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
npm run lint
```

## Editing content

All text lives in `src/content/`:

- `en.ts`, `de.ts`: page text per language
- `skills.ts`, `projects.ts`: skill groups and project cards
- `profile.ts`: email, LinkedIn and GitHub links

CV downloads are served from `public/cv/`. An optional profile photo goes in `public/images/profile.jpg`.
